This visual exploration maps the complex webs of their intellect. By tracing the overlaps between their areas of expertise, their countries of origin, and their eras, we reveal the hidden architecture of genius.

Methodology

I asked Gemini, ChatGPT, Co Pilot, Grok, Indus (Sarvam), Claude, Deep Seek, and Perplexity the same question:

"1. Using the all the responses come up with a list of all the areas of knowledge. While doing this don’t go with just the names used - it is possible that some AI might have used a different name for the same area of knowledge compared to another AI. So, look deeper while coming up with the list.

2. Once you have that list, come up with a list of all the polymaths mentioned and map them to the areas of knowledge you compiled above. Again, while compiling these names, make a deeper analysis - it is possible that the same name got spelled differently in the answers given by different AIs.

3. Using the outputs of the above two steps, create a new table with the following columns:
  a. Name of the polymath
  b. Country of his origin
  c. Time period of his life
  d. The areas of knowledge that he involved in.

4. Present the table that you created in a very simple, easy to read and understandable format"

Then I used Gemini to collate and concord the answers given. The output of this was a CSV file that had the following columns:

Name, Areas of Contribution

This CSV file was used for creating this visualization with the help of Antigravity.
